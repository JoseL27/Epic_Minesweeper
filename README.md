# Epic Minesweeper
This is a minesweeper game made for the sake of learning and experimenting with some gui and game development concepts and tools.

## Quick Start
- Download and extract Buscaminas.zip
- Execute Buscaminas.jar (Some window creating problems in Windows might be solved by executing buscaminas.bat instead)

## For developing
To build, Build -> Build artifact -> Buscaminas.jar

To run, java -jar Buscaminas.jar
